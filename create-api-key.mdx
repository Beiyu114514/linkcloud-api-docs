调用 LinkCloud 前需要先创建 API Key。

**创建入口：[api.linkcloud.sh/keys](https://api.linkcloud.sh/keys)**

## 创建步骤

<Steps>
  <Step title="打开 API 密钥页面">
    登录后进入 [API 密钥页面](https://api.linkcloud.sh/keys)，点击右上角的**创建密钥**。
  </Step>

  <Step title="填写名称">
    用一个便于识别的名称，例如 `claude-code`、`codex-laptop`、`test-script`。为每个客户端或每台机器单独建 Key，出问题时可以直接停用它。
  </Step>

  <Step title="选择分组">
    按下方[分组检查清单](#选择分组)确认后再选。下拉里可以搜索分组。
  </Step>

  <Step title="按需配置限制">
    限额、限速、IP 白名单、有效期都是可选项，留空即为不限。字段说明见[密钥配置项](#密钥配置项)。
  </Step>

  <Step title="创建并保存密钥">
    创建后复制密钥并妥善保存。密钥在列表中可以随时再次复制，也可以点击**轮换凭据**生成新的密钥串（旧密钥立即失效，Key 的 ID、配置和用量记录保留）。
  </Step>
</Steps>

<Note>
页面顶部的 **API Endpoints** 区域列出了当前可用的端点，可一键复制，也可以直接做**测速**。
</Note>

## 选择分组

在[模型广场](https://api.linkcloud.sh/models)找到目标模型，逐项确认：

| 检查项 | 依据 |
| --- | --- |
| 模型 | 分组包含你要调用的完整模型 ID |
| 协议 | 分组支持客户端实际使用的接口格式，不能只按模型厂商判断 |
| 客户端限制 | 分组说明里是否限定了客户端。例如 `claude_max` 仅允许 Claude Code |
| 价格 | 查看该分组的单价、倍率与最高优惠 |
| 可用性 | 查看分组近 7 天的探测可用率和当前容量 |

分组后续可以更换：在密钥列表里点击该 Key 的**分组**列即可切换。

## 密钥配置项

### 基础

| 字段 | 说明 |
| --- | --- |
| 名称 | 用于识别用途，建议按客户端或环境命名 |
| 分组 | Key 绑定的分组，决定可用模型、协议和倍率 |
| 状态 | 启用或禁用。被禁用后使用该 Key 的请求会被拒绝 |
| 自定义密钥 | 可选。手动指定密钥串，需至少 16 个字符，只能包含字母、数字、下划线和连字符 |

### 计费来源与 Fast 模式

| 字段 | 说明 |
| --- | --- |
| 计费来源 | **自动**、**指定订阅**或**仅余额**。选择自动时优先按可用权益扣费 |
| Fast 模式策略 | **跟随请求**、**强制开启**或**强制关闭**。强制开启会让该 Key 的请求走高优先级通道，单价更高 |
| 自动降级 | 分组暂不可用时允许自动降级到其他分组 |

### 模型控制

| 字段 | 说明 |
| --- | --- |
| 复合 Key | 绑定 1–20 个分组，每个分组配一个前缀，请求时用 `前缀/模型ID` 指定。复合 Key 不支持 WebSocket |
| 模型重定向 | 最多 100 条规则。客户端照常发送源模型名，Key 在路由前替换为目标模型。源模型支持一个末尾 `*` 通配，目标必须是具体模型，且源不能重复 |
| 模型白名单 | 只允许分组内指定的模型通过 |

### 限额与限速

| 字段 | 说明 |
| --- | --- |
| 总限额 | 该 Key 的累计消费上限，`0` 表示不限 |
| 5 小时限额 / 日限额 / 7 天限额 | 滚动时间窗口内的消费上限，`0` 表示不限 |
| 并发限制 | 该 Key 同时进行的请求数上限，`0` 表示不限 |
| RPM 限制 | 每分钟允许进入网关的请求数，`0` 表示不限 |

限额用尽后，新请求会被拒绝，并提示对应的超额信息。已用额度可以在密钥页面重置。

<Info>
Key 自身的限制之外，用户级和分组级的限制依然生效。也就是说，Key 留空为「不限」并不代表可以绕过账户层面的限制。
</Info>

### 访问控制与有效期

| 字段 | 说明 |
| --- | --- |
| IP 白名单 | 每行一个 IP 或 CIDR。设置后只有名单内的 IP 可以使用该 Key |
| IP 黑名单 | 每行一个 IP 或 CIDR。命中名单的 IP 会被拒绝 |
| 有效期 | 可设置天数或具体日期，也可以选择永不过期。过期后 Key 自动失效 |

## 在客户端中使用

创建好 Key 后，有两种方式把配置带到客户端：

- **使用密钥**：在密钥列表点击**使用密钥**，页面会按你选择的客户端生成可直接复制的配置，覆盖 Claude Code、Gemini CLI、Codex CLI、Grok CLI 和 OpenCode。
- **导入到 CC-Switch**：点击**导入到 CCS**，在 CC-Switch 弹窗里确认，把 Key 写入 CC-Switch 的供应商配置。见 [CC-Switch 指南](/clients/cc-switch)。

各客户端的完整步骤见[编程客户端](/clients/claude-code)一节。

## 密钥安全

- 不要把 Key 写入公开仓库、前端代码或其他第三方能直接读取的位置。
- 按用途、项目或环境分别建 Key，避免长期共用一个。
- 怀疑泄露时，先禁用旧 Key，再创建替代 Key 并更新客户端；也可以直接轮换凭据。
- 客户端报认证失败时，确认它读取的是最新配置。部分客户端需要完全退出后重启，仅重载窗口不够。
