## 一、概述

您不得使用 LinkCloud 从事任何违法、侵权、欺诈、骚扰、恶意攻击、绕过限制或其他滥用平台资源的行为。

针对部分模型、线路、功能或服务能力，LinkCloud 可能设置额外的使用条件、调用限制或风控要求。相关规则将通过产品页面、官方文档、控制台说明或其他合理方式进行告知；您一旦使用相关能力，即视为同意并承诺遵守该等规则。

## 二、适用范围

本政策适用于以下场景，包括但不限于：

- 使用 LinkCloud 网站、控制台或 API；
- 创建、存储、管理、配置或使用 API Key；
- 通过 Claude Code、Codex、CC-Switch、OpenCode 或其他客户端接入 LinkCloud；
- 基于 LinkCloud 构建自动化流程、机器人、接口、插件或其他功能；
- 通过兼容客户端、自有程序、代理程序或其他集成方式调用 LinkCloud。

通过兼容客户端、自有程序或其他集成方式接入 LinkCloud 本身并不被禁止；但您不得借此绕过 LinkCloud 的鉴权机制、调用配额、速率限制、安全保护、产品规则或其他平台限制。

## 三、禁止的使用行为

### 3.1 非法或侵权行为

您不得使用 LinkCloud 从事、协助、推动或推广任何违法或侵权活动，包括但不限于：

- 诈骗、洗钱、赌博、非法集资或其他违法活动；
- 侵犯知识产权、商业秘密、名誉权、隐私权或其他合法权益；
- 传播、制作、存储或协助传播依法被禁止的内容；
- 违反适用法律法规、监管要求或公序良俗的其他行为。

### 3.2 欺诈、冒充与误导

您不得使用 LinkCloud 生成、传播或自动化输出以下内容：

- 冒充个人、企业、机构、客服、官方或其他身份主体的内容；
- 用于诈骗、社工、钓鱼、诱导转账、虚假宣传或虚假承诺的内容；
- 明知不实仍用于误导、欺骗或操纵他人的内容；
- 批量垃圾内容、垃圾营销、骚扰信息或其他低质量滥发信息。

### 3.3 攻击、绕过与资源滥用

您不得使用 LinkCloud 进行、参与或协助以下行为：

- 入侵、扫描、爆破、撞库、钓鱼、提权、漏洞利用或其他恶意探测行为；
- 编写、传播、优化或部署恶意代码、木马、勒索软件、蠕虫或其他破坏性程序；
- 对任何系统、服务或网络实施 DDoS、资源消耗攻击或其他破坏性行为；
- 绕过或破坏 LinkCloud 或相关服务的鉴权、配额、速率限制、计费逻辑或安全保护；
- 通过异常调用、空转请求、刷量、压测滥用、恶意并发或其他方式不当消耗平台资源。

### 3.4 账户与风控规避

您不得实施以下行为：

- 借用、盗用、冒用他人账户、身份信息或支付手段；
- 通过批量注册、虚假身份、自动化脚本、异常设备环境或其他方式规避平台限制或风控措施；
- 将 API Key 向未获授权的第三方转让、出售、出借、共享或公开披露；
- 规避平台关于账户、计费、额度、线路、模型、权限或调用限制的管理规则。

### 3.5 禁止二次分发

未经 LinkCloud **明确书面授权**，您不得以任何形式对 LinkCloud 的服务、API Key、调用额度、模型渠道、接口能力或其他平台资源进行二次分发、转售、转租、共享、代接入或再包装。

禁止的二次分发行为包括但不限于：

- 将 LinkCloud 的 API Key、调用额度或模型渠道出售、出租、出借、共享给第三方；
- 搭建中转站、分销面板、共享接口、账号池、机器人服务或其他可供第三方调用的服务；
- 将 LinkCloud 作为后端能力包装成自己的 API、SaaS、插件、客户端或自动化服务并向第三方提供；
- 通过拼车、代充、代理销售、私下转让等方式规避 LinkCloud 的账户、计费、配额、权限或风控规则。

如 LinkCloud 发现存在二次分发或疑似二次分发行为，有权立即采取包括但不限于以下措施：

- 封禁相关账户；
- 禁用相关 API Key；
- 暂停或终止全部或部分服务；
- 拒绝退款；
- 视情况追究进一步责任。

### 3.6 隐私与数据权益侵害

您不得：

- 非法收集、出售、交易、公开披露或滥用他人个人信息；
- 使用泄露数据、非公开数据或其他无合法来源的数据进行识别、跟踪、画像、骚扰或其他不当处理；
- 生成、处理、传播侵犯他人隐私、肖像、名誉、身份或其他人格权益的内容。

### 3.7 有害内容

您不得使用 LinkCloud 创建、传播、生成或协助生成以下内容：

- 宣扬自残、自杀、虐待、极端暴力或恐怖活动的内容；
- 仇恨、歧视、骚扰、羞辱或针对特定个人或群体的人身攻击内容；
- 性剥削、未成年人相关不当内容或其他严重有害内容；
- 其他可能造成重大现实伤害、恐慌或社会危害的内容。

### 3.8 高风险使用限制

您不得将 LinkCloud 作为唯一依据，直接用于可能影响个人重大权益或人身、财产安全的决策场景，包括但不限于：

- 医疗诊断、治疗建议或紧急处置；
- 法律判断、诉讼策略或执法决定；
- 金融授信、投资、保险定价或理赔决定；
- 招聘筛选、教育录取、住房资格审核；
- 其他高风险自动化决策场景。

如您在相关场景中使用 LinkCloud，您应自行确保：

- 存在充分的人类复核；
- 必要时向相关主体进行适当披露；
- 相关使用方式符合适用法律法规及监管要求。

## 四、API Key 与账户安全要求

您应妥善保管 LinkCloud 账户及 API Key，并仅在经授权的成员、设备、服务器或集成环境中，按照最小必要原则进行使用。

您应采取合理且必要的安全措施保护 API Key，包括但不限于：

- 不将 API Key 写入公开仓库、公开客户端代码、前端页面或其他可被第三方直接获取的位置；
- 按不同用途、不同项目或不同环境区分使用不同密钥，避免长期混用；
- 发现疑似泄露、误用或异常调用后，及时进行轮换、停用或删除；
- 按照官方文档、产品说明和安全建议正确接入与调用服务。

因您保管不善、配置错误、授权不当或安全措施不足导致的风险、损失或责任，由您自行承担。

## 六、平台执行与处理措施

在存在合理理由表明某一使用行为可能违反本政策、影响平台稳定性、损害其他用户权益或存在安全、合规、风控风险时，LinkCloud 有权根据具体情况采取以下一项或多项措施：

- 要求用户补充说明使用场景或相关信息；
- 临时限制调用频率、模型范围、线路能力或账户权限；
- 禁用相关 API Key；
- 冻结、暂停或终止部分功能或全部服务；
- 对相关请求、配置、项目或账户进行审查与风险控制；
- 在必要时保留进一步追责的权利。

LinkCloud 将结合已知事实、风险程度、处理成本、平台稳定性需求及合规要求，对相关情况进行判断和处理。  
在紧急情况下，LinkCloud 可先行采取必要措施，后续再视情况进行通知、说明或复核。

## 七、申诉与联系

如果您认为账户、API Key、调用请求或相关权限被误判、误限或误封，可通过官方支持渠道联系 LinkCloud，并尽量提供以下信息，以便我们更快协助核查：

- 账户标识；
- API Key 名称、用途或关联项目；
- 问题发生的时间范围；
- 具体使用场景说明；
- 相关报错信息、请求 ID 或其他辅助材料。

您提供的信息越完整，越有助于我们提高核查与处理效率。
