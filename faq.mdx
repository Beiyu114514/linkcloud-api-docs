## 注册与登录

### 可以用什么方式注册？

支持邮箱注册，以及 Google、GitHub、LinuxDO 三种第三方登录。钉钉、OIDC 和微信登录当前未开放。

注册后需要完成邮箱验证。

### 邮箱域名有限制吗？

部分公共邮箱域可以直接注册，企业邮箱需要单独加入白名单。当前允许的域名包括：

`@qq.com`、`@163.com`、`@126.com`、`@sina.com`、`@sohu.com`、`@aliyun.com`、`@foxmail.com`、`@gmail.com`、`@yahoo.com`、`@protonmail.com`、`@mail.com`，以及 `*.edu.cn` 教育域名。

不在名单内的域名会提示 `This email domain is not allowed for registration.`。需要使用企业邮箱时请联系支持添加。

### 支持两步验证吗？

支持。可以开启基于 TOTP 的两步验证（例如手机验证器应用）。通行密钥（Passkey）当前未开放。

### 忘记密码怎么办？

登录页提供找回入口，通过邮箱重置。修改邮箱功能当前未开放。

## 计费

### 为什么同一个模型在不同分组价格不同？

分组决定计费倍率、上游来源、协议支持和可用性。同一个模型 ID 出现在多个分组里时，价格和稳定性都可能不同。详见[核心概念](/concepts#分组)。

### 余额和订阅是什么关系？

余额是账户预付费金额，所有分组通用。如果账户持有订阅，扣费时优先消耗订阅权益，没有可用订阅时才扣余额。当前平台关闭了订阅购买入口，新用户以余额充值为主。

### 为什么会收到余额提醒？

余额低于阈值（默认 `$5`）时，系统会发送提醒邮件。可以在邮件里直接进入充值页。

### 怎么把消费限制在固定预算内？

在 Key 上设置总限额和 5 小时 / 日 / 7 天限额，并配合并发与 RPM 限制。团队场景下，所有者还可以为每个成员设置日 / 周 / 月限额。见[创建 API Key](/create-api-key#限额与限速)。

## 使用

### 支持哪些客户端？

Claude Code、Codex（CLI 与桌面端）、CC-Switch、OpenCode，以及任何 OpenAI 兼容工具。也可以直接用 curl 或 SDK，见[编程客户端](/clients/claude-code)。

### 能在 Claude 桌面版或网页版里用吗？

不能。`claude_max` 分组只接受 Claude Code 官方客户端。要在 Anthropic 协议下使用其他工具，请选择 `claude_kiro` 分组并确认它支持你的客户端。

### 什么是并发？

并发指同一时刻正在处理的请求数。Key、账户和分组都可能有限制，达到上限后新请求会被拒绝或排队。并发限制适合防止脚本失控，比单纯限制 RPM 更能保护上游稳定性。

### 生图怎么计费？

`gpt_image` 分组按张计费，价格只由生成图片的实际尺寸（1K / 2K / 4K）决定。创作台会在提交前显示单张预估成本。

### 为什么客户端里显示的模型和我想的不一样？

部分客户端会自动选择或重写模型名（例如 Codex 的 `codex-auto-review`）。可以用 Key 的**模型重定向**把客户端发送的名字映射到具体模型，见[创建 API Key](/create-api-key#模型控制)。

## 数据与隐私

### LinkCloud 会用我的内容训练模型吗？

不会。LinkCloud 不会使用来自服务的客户内容训练模型。

为了提供服务、排查故障、处理滥用和满足合规要求，平台可能在必要范围内处理请求、响应、日志和账户信息。

### 什么是数据共享分组？

如果某个分组参与数据共享或数据出售，平台会在模型广场、购买页或分组说明里**明确标注**，不会用默认分组或模糊描述的方式启用。你可以选择不购买这类分组。

详细规则见[服务条款](/legal/terms)。
