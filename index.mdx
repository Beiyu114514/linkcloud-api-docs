LinkCloud 是统一的大模型 API 网关。你只需要一个 API Key，就能在 Claude Code、Codex、CC-Switch、OpenCode 或自己的程序里调用 Claude、GPT、Gemini 等模型，不必分别维护各家订阅。

所有请求走同一组端点，计费统一折算到账户余额，用量在控制台里可查。
