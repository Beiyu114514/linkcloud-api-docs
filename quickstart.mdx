下面是从零到第一次成功调用的完整流程。整个过程大约需要 10 分钟。

## 开始之前

你需要：

- 一个 LinkCloud 账号，并完成邮箱验证。支持的邮箱域名见[注册与邮箱](/faq#注册与邮箱)。
- 账户余额。可以在[控制台](https://api.linkcloud.sh/purchase)充值，或使用兑换码。
- 一个已安装好的客户端，例如 [Claude Code](/clients/claude-code) 或 [Codex](/clients/codex)。不想装客户端时，用 [curl](/clients/curl) 也能验证。

## 接入流程

<Steps>
  <Step title="确认目标模型和分组">
    打开[模型广场](https://api.linkcloud.sh/models)，搜索你要用的模型，记下它所属的**分组**。分组决定可用模型、计费倍率、接受的协议格式和客户端限制，详见[模型与分组](/models)。
  </Step>

  <Step title="充值或兑换余额">
    在[充值页面](https://api.linkcloud.sh/purchase)在线充值，或在[兑换页面](https://api.linkcloud.sh/redeem)使用兑换码。计费与扣费顺序见[余额与计费](/account/billing)。
  </Step>

  <Step title="创建 API Key">
    进入[API 密钥页面](https://api.linkcloud.sh/keys)，点击**创建密钥**，填写名称并选择上一步确认的分组。创建后立即复制密钥，详见[创建 API Key](/create-api-key)。
  </Step>

  <Step title="配置客户端">
    在客户端里填入三样东西：端点地址、API Key、模型 ID。按所用客户端查看：

    | 客户端 | 教程 | 适用场景 |
    | --- | --- | --- |
    | Claude Code | [教程](/clients/claude-code) | Anthropic 官方 CLI，终端编程 |
    | Codex | [教程](/clients/codex) | OpenAI 官方 CLI 与桌面端 |
    | CC-Switch | [教程](/clients/cc-switch) | 图形化管理 Claude Code / Codex 配置 |
    | OpenCode | [教程](/clients/opencode) | 开源终端 Agent，多模型切换 |
    | 通用 / 自建程序 | [教程](/clients/curl) | curl、OpenAI SDK、任意兼容客户端 |

    端点地址的选择见 [API 端点](/endpoints)，协议格式见[协议与兼容性](/protocols)。
  </Step>

  <Step title="发送第一条请求">
    在客户端里选择目标模型，新建对话，发送「只回复 OK」。这一步会产生费用。
  </Step>
</Steps>

## 确认接入成功

1. 收到模型的文本回复，而不只是看到模型列表或「配置已保存」提示。
2. 打开[使用记录](https://api.linkcloud.sh/usage)，找到本次请求，核对使用的 Key、模型和扣费金额。
3. 确认扣费金额与你所选分组的倍率相符。

这只能确认本次文本对话成功。如果需要工具调用、图片或流式响应，再单独验证对应能力。

<Note>
收到回复但使用记录里找不到请求时，先核对时间范围、账号和 Key，再检查客户端是否真的发出了请求，见[排障](/troubleshooting)。
</Note>
