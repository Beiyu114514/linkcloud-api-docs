LinkCloud 把调用明细、费用构成和性能数据都放在控制台里。核对账单、定位异常请求、评估缓存效果时，用的都是这几个页面。

## 概览：仪表盘

**入口：[api.linkcloud.sh/dashboard](https://api.linkcloud.sh/dashboard)**

仪表盘给出账户的整体情况：

| 区块 | 内容 |
| --- | --- |
| 用量趋势 | 按小时或按天展示请求数、token、费用和缓存命中率，可与上一周期对比 |
| 实时指标 | 最近 5 分钟的平均 RPM、TPM、平均延迟，以及今日已消费金额 |
| Top 模型 | 按所选指标排名的模型消耗，可点击筛选 |
| 活跃热力图 | 按天、按小时查看使用分布 |
| 最近公告 | 平台公告与维护通知 |
| 快捷操作 | 创建密钥、充值等常用入口 |

## 使用记录

**入口：[api.linkcloud.sh/usage](https://api.linkcloud.sh/usage)**

使用记录是逐条明细，可以按时间范围、API Key、模型、端点、状态筛选。每条记录包含：

- 请求的模型（客户端发送的模型、上游实际模型、上游返回的模型）
- 使用的 Key 与端点
- 输入、输出、缓存读、缓存写的 token 数
- 首字延迟、总耗时、TPS
- 标准价、实际扣费，以及请求状态

### 费用构成

展开单条记录可以看到完整的价格明细：

| 项目 | 说明 |
| --- | --- |
| 输入 / 输出 | 按「每 1M tokens」的单价计算 |
| 缓存读 | 命中提示缓存的部分，单价通常低于输入 |
| 缓存写（5m / 1h） | 写入缓存的部分，按 TTL 分档计价 |
| 图片 | 按张计价，并记录计费尺寸与输入、输出尺寸 |
| 标准价 / 实际扣费 | 标准价基于模型基础定价；实际扣费叠加分组倍率等因素 |

<Info>
**标准价**不受分组倍率和专属折扣影响，**实际扣费**才是从余额里扣掉的金额。两者不一致是正常的，差额来源见[余额与计费](/account/billing#计费规则)。
</Info>

### 缓存与性能

- **缓存命中率**：缓存读 token 占输入 token 的比例，缓存命中率高时费用明显更低。
- **首字延迟**：从请求发出到收到第一个输出片段的时间。
- **TPS**：输出 token 数除以从上游调用开始到最后一段有效内容的时间。它包含连接、等待、预填充和推理时间，也会受网络和下游背压影响。

不同分组对缓存的支持不同。例如 `claude_kiro` 分组不保证缓存命中率，输出风格也与官方有差异。

## 用量查询

**入口：[api.linkcloud.sh/key-usage](https://api.linkcloud.sh/key-usage)**

按 Key 维度查看消耗情况，适合快速回答「这个 Key 用了多少」。逐条明细仍然看使用记录。

## 用量排行

**入口：[api.linkcloud.sh/usage-ranking](https://api.linkcloud.sh/usage-ranking)**

展示平台内用量靠前的账户，默认按总 token 排序，最多显示 50 名。榜单可以显示请求数、总 token 和实际消费。只想用自己账户的数据时，不必关注这个页面。

## 导出 CSV

使用记录页面支持导出，适合做离线分析或对账：

<Steps>
  <Step title="设置导出条件">
    选择时间窗口与筛选条件。可以只导出当前页面的筛选结果，也可以忽略筛选、导出整个时间窗口。
  </Step>

  <Step title="选择时区">
    导出任务需要显式指定时区，也可以切换为 UTC。时间戳为秒级精度。
  </Step>

  <Step title="创建后台任务">
    点击**创建导出任务**。任务在后台执行，页面会显示进度与导出行数。
  </Step>

  <Step title="下载文件">
    完成后下载 CSV。文件为 UTF-8 带 BOM，下载链接保留 24 小时，过期后需要重新导出。
  </Step>
</Steps>
