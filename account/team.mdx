团队功能适合多人协作：成员各自创建密钥，但统一使用**团队所有者**的余额、订阅和分组权益。

**入口：[api.linkcloud.sh/team](https://api.linkcloud.sh/team)**

## 角色与权限

| 角色 | 能做什么 |
| --- | --- |
| 所有者 | 邀请成员、设置成员默认限额、调整每个成员的日 / 周 / 月限额、查看全部成员用量、禁用成员密钥、转让所有权、解散团队 |
| 成员 | 查看自己的限额与用量、创建团队密钥、退出团队 |

普通成员**看不到**其他成员的用量，也看不到所有者的余额与订阅详情。

## 创建团队

<Steps>
  <Step title="创建团队">
    在团队页面创建团队。创建者成为所有者，团队会出现在成员列表中。
  </Step>

  <Step title="设置成员默认限额">
    新成员加入时自动继承这里的日、周、月限额。填 `0` 表示不限额。
  </Step>

  <Step title="邀请成员">
    发送定向邀请。成员接受后即加入团队，并继承默认限额。
  </Step>
</Steps>

## 团队密钥

团队创建后，[API 密钥页面](https://api.linkcloud.sh/keys) 顶部会出现**个人密钥 / 团队密钥**切换菜单。切换到团队密钥后创建的 Key 使用团队权益。

| 行为 | 说明 |
| --- | --- |
| 归属 | 密钥归**创建者**管理 |
| 计费 | 从团队所有者的余额和订阅扣费 |
| 所有者权限 | 可以查看密钥名称、归属成员，并禁用或删除 |
| 成员权限 | 可以创建、查看和管理自己的团队密钥 |

<Warning>
如果某把团队密钥被所有者禁用，成员无法自行重新启用，需要联系所有者处理。
</Warning>

## 成员限额

所有者可以在团队概览中为每名成员单独设置：

| 限额 | 说明 |
| --- | --- |
| 日限额 | 单个自然日内可消费的金额 |
| 周限额 | 单个自然周内可消费的金额 |
| 月限额 | 单个自然月内可消费的金额 |

达到任一限额后，该成员发起的团队请求会被拒绝，直到窗口重置或所有者调整限额。

<Note>
服务端时区为 `Asia/Shanghai`（UTC+08:00），限额窗口按该时区计算。
</Note>

## 用量查看

团队产生用量后，使用记录会多出两类视图：

- **成员消费趋势**：按时间观察每名成员的消耗变化。
- **成员消费对比**：对比成员之间的用量差异。

明细表会标注实际发起请求的成员，便于把费用归到具体的人。

## 所有权与退出

- **转让所有权**：所有者可以把团队转给其他成员，转让需要对方确认。
- **退出团队**：成员可以主动退出。退出后，其团队密钥会被禁用。
- **解散团队**：解散后所有团队密钥立即失效，操作前请确认没有仍在使用的集成。
